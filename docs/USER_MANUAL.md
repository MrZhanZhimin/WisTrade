## 🚀 快速开始

### 系统要求

- **操作系统**: Windows 10/11 (推荐), macOS 10.15+, Linux
- **Python**: 3.11 或更高版本
- **内存**: 至少 8GB RAM
- **硬盘**: 至少 5GB 可用空间
- **网络**: 稳定的互联网连接

### 五分钟上手

```bash
# 1. 克隆项目
git clone https://github.com/MrZhanZhimin/WisTrade.git
cd WisTrade

# 2. 创建虚拟环境
python -m venv venv

# Windows激活
venv\Scripts\activate

# macOS/Linux激活
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置环境变量
cp .env.example .env
# 用文本编辑器打开.env，填入API密钥

# 5. 启动应用
python -m wistrade.main
```

## ⚙️ 安装配置

### 1. 获取必要密钥

#### 智谱AI API密钥 (必需)

1. 访问 [智谱AI开放平台](https://open.bigmodel.cn/)
2. 注册并登录账号
3. 进入"API密钥管理"
4. 创建新密钥，复制保存

**费用**: 新用户赠送免费额度，足够测试使用

#### Tushare Token (可选，推荐)

1. 访问 [Tushare Pro](https://tushare.pro/)
2. 注册并登录
3. 进入"个人中心" → "接口Token"
4. 复制Token

**费用**: 免费版有积分限制，付费版数据更全面

#### QMT客户端 (必需，用于实盘)

1. 联系您的券商（招商证券、光大证券等）
2. 申请开通量化交易权限
3. 下载并安装QMT客户端
4. 确保账户资产满足最低要求（通常10万元）

### 2. 配置.env文件

打开`.env`文件，填写以下内容：

```bash
# AI服务 (必需)
ZHIPUAI_API_KEY=your_zhipuai_api_key_here

# 数据源 (可选)
TUSHARE_TOKEN=your_tushare_token_here

# 数据库加密密码 (必需，请设置强密码)
DB_ENCRYPTION_KEY=请设置一个32位以上的强密码

# 应用环境
APP_ENV=development
LOG_LEVEL=INFO
DEBUG=true

# 安全密钥 (必需)
SECRET_KEY=请使用以下命令生成:
# python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 3. 配置settings.yaml

主要配置项位于`config/settings.yaml`，首次启动会自动创建。

#### 券商配置

```yaml
brokers:
  default: "zhao_shang"
  
  zhao_shang:
    name: "招商证券"
    type: "qmt"
    enabled: true
    qmt_path: ""  # 留空自动检测，或填写QMT安装路径
    account_min_assets: 100000
```

#### AI配置

```yaml
ai:
  provider: "zhipuai"
  model: "glm-4-plus"  # 推荐使用Plus版本
  temperature: 0.7     # 创造性程度 (0-1)
  max_tokens: 4000     # 最大生成长度
  timeout: 60          # 超时时间(秒)
```

#### 风险控制配置

```yaml
trading:
  risk:
    max_position_pct: 0.20      # 单股最大仓位20%
    max_daily_loss_pct: 0.05    # 日最大亏损5%
    max_sector_exposure_pct: 0.40  # 单板块最大敞口40%
    max_orders_per_second: 40   # 每秒最大订单数
    max_orders_per_day: 3000    # 每日最大订单数
    enable_auto_stop_loss: true  # 启用自动止损
    enable_auto_take_profit: true  # 启用自动止盈
```

## 🎯 核心功能

### 1. 仪表盘

**功能**: 实时查看账户状态和持仓情况

#### 账户概览卡片

- **总资产**: 账户总资产及较昨日变化
- **今日盈亏**: 实时盈亏金额和百分比
- **持仓市值**: 当前持仓总市值
- **可用资金**: 可用于交易的现金

#### 资产曲线图

- 显示最近30天的资产变化趋势
- 悬停查看具体日期和金额
- 支持缩放和拖动

#### 持仓列表

| 列名 | 说明 |
|------|------|
| 代码 | 股票代码 |
| 名称 | 股票名称 |
| 数量 | 持股数量 |
| 成本价 | 买入均价 |
| 现价 | 当前价格 |
| 盈亏 | 盈亏金额 |
| 盈亏% | 盈亏百分比 |
| 操作 | 卖出按钮 |

**颜色标识**:
- 🟢 绿色: 盈利
- 🔴 红色: 亏损
- ⚪ 灰色: 持平

#### 实时行情快照

显示自选股列表，实时更新价格和涨跌幅

### 2. 交易页面

**功能**: 执行买卖操作和管理订单

#### 股票搜索

1. 在搜索框输入股票代码或名称
2. 从下拉列表选择股票
3. 自动加载该股票的行情信息

#### 交易面板

**买入操作**:
1. 切换到"买入"标签
2. 输入价格（默认当前价）
3. 输入数量
   - 点击"1/3"、"1/2"、"全仓"快速选择
4. 查看预估金额
5. 点击"买入"确认

**卖出操作**:
1. 切换到"卖出"标签
2. 选择持仓股票
3. 输入价格和数量
4. 点击"卖出"确认

#### K线图

- **时间周期**: 日K、周K、月K切换
- **技术指标**: 
  - MA（移动平均线）
  - MACD（指数平滑异同移动平均线）
  - KDJ（随机指标）
- **交互**: 
  - 鼠标滚轮缩放
  - 拖动平移
  - 悬停查看OHLCV数据

#### 订单管理

**当前委托**:
- 显示所有未成交订单
- 支持撤单操作
- 实时更新状态

**成交记录**:
- 显示历史成交
- 可按日期、股票筛选

### 3. 分析页面

**功能**: 查看交易绩效和市场分析

#### 绩效指标

- **总收益率**: 累计收益率

- **夏普比率**: 风险调整后收益

- 颜色深浅表示收益大小

#### 持仓分布

- 饼图展示行业分布
- 鼠标悬停显示详情
- 点击跳转到持仓

#### 交易统计

| 指标 | 说明 |
|------|------|
| 总交易次数 | 所有交易数量 |
| 胜率 | 盈利交易占比 |
| 盈亏比 | 平均盈利/平均亏损 |
| 平均持仓 | 平均持仓天数 |
| 最大连胜 | 最大连续盈利次数 |
| 最大连亏 | 最大连续亏损次数 |

## 🤖 AI助手使用

### 功能概述

AI助手基于GLM-4.7大模型，提供:
- 市场分析
- 选股推荐
- 策略生成
- 风险预警
- 投资问答

### 使用方式

#### 1. 快捷功能按钮

点击顶部功能按钮:

- **市场分析**: AI分析当前市场趋势和热点
- **选股推荐**: 基于您的偏好推荐股票
- **策略生成**: 自动生成交易策略
- **风险预警**: 检查持仓风险

#### 2. 自由对话

在输入框输入问题，例如:
```
"分析一下平安银行的投资价值"
"为什么我的持仓今天跌这么多？"
"推荐几只科技股"
"帮我生成一个低风险策略"
```

#### 3. 快捷指令

右侧面板提供常用指令，点击即可发送:
- 分析大盘走势
- 推荐价值股
- 生成定投策略
- 检查账户风险

### AI状态面板

- **当前模型**: 显示使用的AI模型
- **连接状态**: 在线/离线
- **Token用量**: 今日已用Token数量
- **API状态**: API密钥是否有效

### 使用技巧

1. **具体化问题**: 
   - ❌ "推荐股票"
   - ✅ "推荐3只低估值银行股"

2. **提供上下文**:
   - ❌ "这只股票怎么样？"
   - ✅ "平安银行(000001)适合长期持有吗？"

3. **逐步追问**:
   - 先问"分析茅台的投资价值"
   - 再问"什么价位买入合适？"
   - 最后问"仓位应该多少？"

## 💼 账户管理

### 添加券商账户

1. 进入"设置" → "账户管理"
2. 选择券商类型
3. 填写账户信息:
   - 账户ID
   - QMT路径（可选）
4. 点击"测试连接"
5. 连接成功后点击"保存"

### 切换账户

1. 在顶部状态栏点击账户名
2. 从下拉列表选择其他账户
3. 系统自动切换并刷新数据

### 账户安全

- 所有凭证使用AES-256加密存储
- 数据库使用PBKDF2密钥派生
- 定期备份账户配置
- 不要在公共电脑保存密码

## 📊 策略管理

### AI策略生成

1. 进入"AI助手"页面
2. 点击"策略生成"按钮
3. 或输入: "根据我的账户生成一个稳健策略"
4. AI会分析:
   - 您的资金规模
   - 风险偏好
   - 市场环境
5. 生成策略包含:
   - 策略名称
   - 选股标准
   - 仓位管理
   - 止损止盈
   - 风险控制

### 启动策略

1. 在"交易"页面找到"AI策略面板"
2. 查看AI推荐的策略
3. 点击"启动"按钮
4. 确认策略参数
5. 系统开始自动执行

### 监控策略

- 实时显示策略状态
- 查看已执行订单
- 查看当前持仓
- 查看盈亏情况

### 停止策略

1. 在"AI策略面板"
2. 找到运行中的策略
3. 点击"停止"按钮
4. 系统停止新建仓位
5. 现有持仓保持不变

## 🛡️ 风险控制

### 风险限制设置

进入"设置" → "风险控制":

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 单股最大仓位 | 20% | 单只股票不超过总资产的20% |
| 日最大亏损 | 5% | 单日亏损超过5%停止交易 |
| 单板块敞口 | 40% | 单个行业不超过总资产的40% |
| 每秒订单数 | 40 | 避免被识别为高频交易 |
| 每日订单数 | 3000 | 合规限制 |

### 自动止损止盈

**启用自动止损**:
1. 设置"止损比例"（如-5%）
2. 当持仓亏损达到设定值
3. 系统自动卖出

**启用自动止盈**:
1. 设置"止盈比例"（如+10%）
2. 当持仓盈利达到设定值
3. 系统自动卖出

### 风险预警

AI会定期检查:
- 仓位集中度
- 行业集中度
- 市场整体风险
- 个股异常波动

发现风险时会:
- 桌面通知提醒
- 声音警告
- 日志记录

## ❓ 常见问题

### Q1: 启动时提示"缺少依赖"

**解决方案**:
```bash
pip install -r requirements.txt
```

### Q2: 无法连接券商

**检查项**:
1. QMT客户端是否已启动
2. 账户ID是否正确
3. 网络连接是否正常
4. 账户权限是否已开通

### Q3: AI不响应

**检查项**:
1. API密钥是否正确
2. 网络是否可访问智谱AI
3. Token额度是否用尽
4. 查看日志了解详细错误

### Q4: 行情数据不更新

**解决方案**:
1. 点击"刷新"按钮
2. 检查数据源状态
3. 清除缓存: 设置 → 数据源 → 清除缓存

### Q5: 订单提交失败

**常见原因**:
- 资金不足
- 股票停牌
- 涨跌停限制
- 交易时间外
- 风险限制触发

### Q6: 如何备份数据

**手动备份**:
1. 复制`data/`目录
2. 复制`config/`目录
3. 复制`.env`文件（注意保密）

### Q7: 如何重置应用

```bash
# 删除数据库
rm data/wistrade.db

# 重置配置
cp .env.example .env

# 重新启动
python -m wistrade.main
```

## ⚠️ 风险提示

### 重要声明

**WisTrade仅供教育和研究使用，不构成投资建议。**

### 股市风险

1. **市场风险**: 股票价格波动可能导致损失
2. **流动性风险**: 可能无法及时卖出股票
3. **系统风险**: 技术故障可能导致交易失败
4. **策略风险**: AI策略可能判断失误

### 使用建议

1. ✅ 充分了解风险后再使用
2. ✅ 从小额资金开始测试
3. ✅ 定期检查账户和策略
4. ✅ 设置合理的止损止盈
5. ✅ 不要投入超过承受能力的资金

### 禁止事项

1. ❌ 不要使用借贷资金交易
2. ❌ 不要忽视风险警告
3. ❌ 不要盲目信任AI推荐
4. ❌ 不要在无人看管时长时间运行
5. ❌ 不要违反当地证券法规

### 合规要求

- 确保已开通券商API权限
- 遵守交易频率限制
- 保留5年交易记录
- 如有疑问咨询专业顾问
